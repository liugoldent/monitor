# 純 EF 第二帳戶對沖

這是永豐帳戶 2 的唯一策略方向。它只觀察十二套 EF 的合成淨部位，原始 EF、H 與
永豐帳戶 1 都繼續運作；本策略不停止來源策略，也不把 H 納入判斷。

## 暫定規則

目前研究候選為：

1. 純 EF 淨口數絕對值至少 3 口。
2. 價格曾沿 EF 方向前進至少 200 點。
3. 價格再從有利峰值回吐至少 50 點。
4. 永豐帳戶 2 建立與當下純 EF 淨部位反向、等量的 TMF 部位。
5. EF 淨口數改變時同步調整對沖；EF 歸零或反向時解除原方向對沖。

這是保護獲利的「合成退出」，不是預測反轉，也不是停止 EF 程式。

## 安全狀態

- 目前只有規格，沒有可執行的實單程式，避免誤下單。
- 下一步先建立可重跑回測與 shadow 服務。
- 至少累積 50 次全新觸發並驗證成本後回撤確實下降，才評估實單。
- 實單必須使用帳戶 2 專屬 API key、明確選定第二期貨帳戶，且不得回退使用帳戶 1 憑證。
- 上線前必須具備最大對沖口數、資料過期、狀態不一致、重啟與防重送保護。

詳細參數、績效快照與待辦保存在本機研究文件，不提交 GitHub。
