# 純 EF 第二帳戶漸進對沖

這是永豐帳戶 2 的唯一策略方向。它只觀察十二套 EF 的合成淨部位，原始 EF、H 與
永豐帳戶 1 都繼續運作；本策略不停止來源策略，也不把 H 納入判斷。

## 目標

這個策略不是把純 EF 全額鎖住，而是保護「高口數後才追價加上的邊際部位」。
核心倉位繼續跟著 EF 趨勢運作；只有在後段加碼後動能衰退時，帳戶 2 才從一口開始、
逐步建立反向部位，避免最後幾口在反轉時吃掉前面的浮盈。

## 待回測規則

1. 純 EF 淨口數絕對值達到 5 口時，只進入觀察狀態，不立即對沖。
2. 門檻以上每次同方向加碼都記為一層「後段加碼」，保存進場時間、價格與進場後有利峰值。
3. 最後一層出現追高風險時才啟動第一口對沖。判斷條件研究三類：最後一口由賺轉賠、
   從進場後峰值回檔，以及一段時間未再創順向新高。
4. 回檔繼續擴大時才逐口增加對沖；上限以仍存在的後段加碼層數與風控上限為準，
   預設不得把純 EF 全額對沖。
5. 趨勢恢復創新高時逐口解除；EF 自行減碼、歸零或反向時，立即同步縮減多餘對沖。

這是替最後幾口加裝煞車，不是預測反轉、停止 EF，或把整段趨勢曝險歸零。
5 口是 2026-06-24～2026-09-10 初步回放得到的研究門檻，不是永遠固定的實單參數。
回檔距離、等待時間與最大對沖口數仍未定案，必須繼續用無前視事件回放比較。

## 門檻研究摘要

- 第 4 口的單層平均損益仍為 +22.9 點；第 5 口降為 -24.0 點，是第一個明顯轉負的層級。
- 合併第 5 口以上共 106 個樣本，平均 -8.2 點、勝率 41.5%；若計入來回成本會更差。
- 27 組相同漸進規則中，以 5 口啟動觀察的組合全部降低樣本內最大回撤，中位改善
  913.8 點；但中位總損益也少 988.0 點，因此它是風控交換，不是加獲利保證。
- 9、10 口雖在樣本內獲利，但只有 5 與 1 個樣本，不足以推翻 5 口門檻。

## 安全狀態

- 目前只有規格，沒有可執行的實單程式，避免誤下單。
- 下一步先建立可重跑的逐層回測與 shadow 服務。
- 至少累積 50 次全新觸發並驗證成本後回撤確實下降，才評估實單。
- 實單必須使用帳戶 2 專屬 API key、明確選定第二期貨帳戶，且不得回退使用帳戶 1 憑證。
- 上線前必須具備最大對沖口數、資料過期、狀態不一致、重啟與防重送保護。
